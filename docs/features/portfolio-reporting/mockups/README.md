# Portfolio reporting — dashboard mockups

Static wireframes for the **dashboard-first** portfolio reports surface (Phase 0 reference). Open `overview.html` in a browser.

## What these show

- **Portfolio Overview:** KPI strip, planned days by staffing bucket (donut placeholder), top epics by days, portfolio cost composition, lens shortcut chips, and a **drawer** state for the full table.
- **Lens pattern (one row):** KPIs + chart placeholders + Top 5 + “View full table”.

Implementation in the app follows this hierarchy: charts and ranked lists first; dense matrices open in a slide-over drawer.
